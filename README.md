# Androws 11 — ROCARDAN SYSTEMS
Launcher Android 15+ com interface HTML/CSS/JS em WebView e ponte Kotlin.

## Compilar
Envie o conteúdo desta pasta para a raiz de um repositório GitHub. Em Actions, execute **Gerar APK Androws 11**. Baixe o artefato `Androws11-APK`.

## Personalizar
Edite `app/src/main/assets/index.html`. A interface funciona offline.

## Limites desta primeira versão
Protótipo funcional inicial: abre aplicativos instalados, mostra relógio, busca e troca cores. Não inclui importação externa de temas, widgets Android reais, notificações nem tela de bloqueio. O APK gerado pelo workflow é debug, não assinado para publicação na Play Store. O Android precisa permitir escolher Androws 11 como app de tela inicial.
